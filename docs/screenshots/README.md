# Screenshots

Real captures of the React Native browser preview, using synthetic data only.

- `overview.png`: desktop dashboard from the explicit sample tour.
- `welcome.png`: desktop onboarding, with no user-entered information.
- `mobile-overview.png`: phone dashboard.
- `mobile-ledger.png`: recorded cash ledger with sample income and expenses.
- `mobile-loan.png`: a fictional tracking-only loan to **Aarav (demo)**.
- `mobile-notes.png`: a fictional pinned financial note linked to that loan.
- `mobile-insights.png`: sample trends and category spending.
- `mobile-settings.png`: sample account labels and optional backup settings.

The six mobile images use a 400 × 864 CSS-pixel viewport at 2× pixel density, saved as 800 × 1728 PNGs. These show the phone layout in Chrome's device preview; they are not Android device screenshots and do not demonstrate native camera, payment or Google authorization dialogs.

All amounts, people, notes and account labels are synthetic. Banks in the explicit sample tour are not defaults for real users. No real financial records, notification text, personal OAuth details, device status bars or private user screenshots are included.
